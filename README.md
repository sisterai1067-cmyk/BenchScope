## 왜 이 프로젝트인가

신약 개발 초기 단계인 가상 스크리닝(Virtual Screening)에 분자 그래프 신경망(GNN)이 광범위하게 도입되고 있지만, 벤치마크에서 높은 AUROC를 기록한 모델이 실제 습식 실험(Wet-lab)에서는 가짜 양성(False Positive) 물질만 선별해 막대한 R&D 예산을 태우는 **'AI 전환(AX)의 역설'**이 반복된다.

원인은 신경망의 용량(Capacity) 부족이 아니라 **'잘못된 교과서(데이터셋)'**와 **'다중 데이터 통합 방식'**에 있다.
1. **시험관 아티팩트(Assay Trap)와 지름길 학습:** 실제 표적 결합력이 없는데도 기름기가 많거나($\text{LogP} > 5.0$) 평면 다중고리 구조($\text{FracCSP3} \le 0.15$) 때문에 수용액에서 자기들끼리 엉겨 붙어(침전·응집) 실험 기계를 속이는 분자들이 존재한다. 단일 출력 헤드 GNN은 복잡한 결합 위상 대신 이 쉬운 1차원 물성 지름길만 외워버린다.
2. **구조 표현 붕괴(Representation Collapse):** 거리 편향을 억제한 정제 벤치마크(MUV)는 오답(비활성 디코이)이 99.80%(1:510)에 달한다. 이 극단적 불균형 환경에서 신경망은 오답 벌점을 피하려고 구조 판별 가중치를 포기하고 모든 분자에 똑같은 음수 상수 점수(표준편차 `0.311`)만 내뱉는다.
3. **다중 DB 병합 시의 기저율 집단 교란(Group Confounding):** 표현 붕괴를 깨려고 여러 기관의 독성·임상 데이터셋을 단순 병합하면, 기관별 정답 비율(기저율 0.73% vs 76.51%, 105.26배 격차) 차이 때문에 실제로는 직교하는 구조 점수와 편향 점수 사이에 거대한 가짜 상관(전체 공분산의 **98.5%가 절편 거품**)이 유도된다.

**BenchScope**는 무분별한 초거대 모델 도입 대신 **백본 크기를 201,733개 파라미터로 100% 고정**한 채, 표현을 **'순수 구조 축'**과 **'5차원 생물약제학 편향 축'**으로 비순환 직교 분리하고 **무파라미터 채널 중심화**로 집단 교란을 제거해 R&D 의사결정 품질을 복원한다.

## 4단계 거버넌스 프레임워크

제약·바이오 데이터 플랫폼에서 데이터를 단 1건도 인위적으로 삭제하지 않고(Zero-Deletion), 학습부터 추론·감사까지 닫힌 루프(Closed-Loop)로 작동하는 4단계 거버넌스를 구성했다.

| Stage | 이름 | 포착 및 제어 대상 | 핵심 수리·도메인 메커니즘 |
| :---: | :--- | :--- | :--- |
| **S1** | **무손실 5축 편향 정량화** | 분자 크기·골격 독점·시험관 함정 | 샘플 삭제 없이 골격 역가중치($w_{\text{red}}$), 크기 적응형 온도($\tau_i = \sqrt{24/N_i}$), 5D 물성 텐서($\text{MW, LogP, TPSA, FracCSP3}, I_{\text{trap}}$) 분리 구축 |
| **S2** | **3층위 채널 중심화 직교 학습** | 다중 DB 기저율 절편 교란 | 아키텍처 수준 채널 평균 차감(`Cov_between = 0.0000` 소거) + 기저율 절편($b_t$) 분리 + 내부 직교 페널티($\mathcal{L}_{\text{ortho}}$) 및 어텐션 샤프닝 |
| **S3** | **절편 보존 탈편향 추론** | 추론 시 음수 절편 소실 왜곡 | 단순 마스킹($L_{\text{bias}}=0$) 시 발생하는 확률 역전을 막기 위해 분자별 물성 편차만 도려내는 보정식($L_{\text{carved}} = \hat{z}_{\text{struct}} + b_t$) 적용 |
| **S4** | **상한선 검증 & 신호등 감사** | 초기 선별 무결성 및 타깃 오염도 | Truchon & Bayly 표준 $\text{BEDROC}$ 이론 상한($\text{Ceiling}$) 수리 검증 + 타깃별 3등급 신호등(`Red` / `Amber` / `Green`) 예산 집행 처방 |

### 핵심 설계 결정

1. **백본 파라미터 100% 동결 (201,733개 고정)** — 대조군(V1, 단일 MUV 17채널)과 실험군(V2, 5대 코퍼스 59채널)이 44개 학습 파라미터 텐서(BatchNorm 버퍼 포함 68개 텐서, `201,733`개 파라미터)를 단 1개의 차이도 없이 동일하게 공유한다. V2에서 증가한 `3,980`개(`+1.88%`)는 전량 59채널 출력 포트와 5번째 편향 축(`FracCSP3`) 확장에만 쓰였다. 이로써 성능 향상이 모델 대형화 덕분이 아니라 순수하게 **데이터-모델 직교 거버넌스**의 효과임을 엄밀하게 통제 증명했다.
2. **무손실(Zero-Deletion) 보존** — 리핀스키 법칙 등을 벗어난 외곽 이상치(Outlier) 분자를 인위적으로 삭제하면 혁신 신약(First-in-Class) 후보 자산까지 소실된다. 샘플은 단 1건도 버리지 않고, 편향 전담 헤드(`bias_only_head`)가 시험관 응집·침전 노이즈만 스펀지처럼 흡수한 뒤 추론 시 도려낸다(Carving).

## Structural Channel Centering (SCC)

다중 기관 데이터셋(MUV 기저율 0.73%, $\mu = -4.9169$ vs BBBP 기저율 76.51%, $\mu = +1.1807$)을 단순 병합하면, 각 채널 내부에서는 구조와 물성 편향이 직교($r_{\text{within}} = -0.0120$, 사잇각 $89.3^\circ$)하더라도 채널 간 절편 차이($\Delta\mu = 6.0976$)가 전체 공분산의 **98.5%(`Cov_between = 1.1423`)**를 거품처럼 덮어버린다.

SCC는 학습 파라미터를 단 1개도 추가하지 않고(0-Param) 출력 직후 채널별 평균을 실시간 차감하여 전공분산 법칙의 그룹 간 공분산 항을 항등적으로 0으로 소거한다.

```python
# core/centering.py
class StructuralChannelCentering(nn.Module):
    """[Layer-1 Governance] 무파라미터(0-Param) 구조적 채널 중심화 투영 계층"""

    def __init__(self, num_channels: int = 59, momentum: float = 0.1):
        super().__init__()
        self.register_buffer("running_mean", torch.zeros(1, num_channels), persistent=False)
        self.register_buffer("initialized", torch.tensor(False, dtype=torch.bool), persistent=False)
        self.momentum = momentum

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        """
        z: (B, num_channels) — 채널별 원시 로짓 (L_struct 또는 L_bias)
        return: (B, num_channels) — Cov_between = 0.0000이 보장된 중심화 잔차 (z_hat)
        """
        if self.training and z.size(0) > 1:
            b_mean = z.mean(dim=0, keepdim=True)
            with torch.no_grad():
                if not self.initialized:
                    self.running_mean.copy_(b_mean)
                    self.initialized.fill_(True)
                else:
                    self.running_mean.mul_(1.0 - self.momentum).add_(b_mean * self.momentum)
            return z - b_mean
        return z - (z.mean(dim=0, keepdim=True) if z.size(0) >= 2 else self.running_mean)
```

이 중심화 투영($\bm{\Sigma}_B = \mathbf{0}$) 위에 채널 내부 직교 정규화($r_{\text{within}} \to 0 \implies \bm{\Sigma}_W \to \mathbf{I}_2$)가 결합되면, 신경망 출력 공간에서의 표준화 유클리드 거리가 곧 공분산을 보정한 **마할라노비스 거리(Mahalanobis Distance)**와 수학적으로 일치하게 된다(보정 계수 오차 `0.014%` 미만).

## 데이터

### 마주친 벽: 단일 정제 코퍼스(MUV)의 온실 효과와 불균형 딜레마

거리 편향이 통제된 대표 벤치마크인 `MUV`(93,087건, 17채널)를 RDKit으로 전수 감사한 결과, 단독 학습 시 실전 일반화를 가로막는 3가지 구조적 결함이 확인되었다.
* **중원자 수 온실 효과:** 사분위수(IQR)가 21~28개(중앙값 24개)에 갇혀 있어 소형 단편($\le 12$원자, 0.4%)과 거대 분자($\ge 35$원자, 1.9%)가 결핍되어 있다. 반면 실전 스크리닝 타깃인 `ogbg-molhiv` 활성 분자의 **81.5%**, `ogbg-molpcba` 활성 분자의 **53.6%**는 이 온실 구간 밖에 존재한다.
* **극단적 디코이 과잉 (1 : 510.01):** 유효 라벨 249,886개 중 활성 정답은 단 **489개(0.20%)**뿐이다.
* **평면 응집 함정과 4D 헤드의 한계:** 완전 평면 분자($\text{FracCSP3} = 0$)가 2,789건 존재하며, `molhiv` 활성 분자의 **61.5%**가 트랩 경계 영역에 위치한다.

## 한계와 향후 과제

### 한계 (솔직하게)
* 통제 변인 실험(용량 효과 배제)을 위해 경량 4계층 2D `GINEConv` 백본(201,733개 파라미터)과 단일 시드(`seed = 42`)를 사용했다. 최신 3D 등변 신경망(Equivariant GNN)이나 대규모 그래프 트랜스포머 대비 절대적인 예측 상한선은 낮다.
* 리간드 2D 분자 그래프만 입력받으므로 표적 단백질의 3D 바인딩 포켓 구조나 유도 적합(Induced Fit) 에너지는 직접 계산하지 못한다.
* 생물약제학 함정 임계값($\text{LogP} > 5.0, \text{TPSA} > 120\text{ \AA}^2, \text{FracCSP3} \le 0.15$)은 전통적인 저분자 합성 신약(Small Molecules) 기준이므로 중분자 모달리티에는 그대로 적용할 수 없다.

### 향후 과제
* [ ] **SOTA 파운데이션 백본 플러그인 결합:** 본 연구의 양갈래 직교 헤드와 `StructuralChannelCentering`은 백본 무관(Backbone-Agnostic) 모듈이므로, 3D Equivariant GNN 및 대규모 분자 파운데이션 모델 뒷단에 이식하여 절대 스크리닝 성능 극대화
* [ ] **중분자 모달리티(PROTAC · 거대고리 펩타이드) 적응형 영점 보정:** 모달리티별 기준 분포에 맞춰 5차원 편향 텐서의 영점(Reference Frame)을 자동 재설정하는 모듈 확장
* [ ] **다기관 의료 데이터 스페이스 Quality Gate API 실증:** 병원·연구소 컨소시엄 데이터 병합 시 상류(Upstream)에서 기저율 절편 교란과 쌍둥이 누수를 실시간 감사하는 B2B 파이프라인 배포
